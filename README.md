# Capture Success

Product-quality portfolio site for Capture Success, built with the Next.js App Router and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

The homepage is statically rendered. Motion is progressive, respects reduced-motion preferences, and keeps all primary content available without JavaScript.
